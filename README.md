# КИП — чек-лист v21

Статическая версия чек-листа для публикации через GitHub Pages. В v21 добавлены переключаемые страницы, четыре темы оформления, сброс всех отметок и импорт КИП-тегов из Excel/текстовых файлов. Все функции v20, включая OCR.space Engine 2 → 3, сохранены.

## Импорт файлов

- Поддерживаются XLSX, XLS, CSV, TSV, TXT и JSON.
- CSV, TXT и JSON читаются локально, без отправки файла в сеть.
- Для XLSX/XLS приложение при первом импорте загружает SheetJS с публичного CDN `cdn.jsdelivr.net`; сам файл остаётся в браузере.
- Для PDF или Word сначала сохраните нужную таблицу как CSV или Excel.

## Публикация
1. Создать отдельный публичный GitHub repository.
2. Загрузить `index.html`, `.nojekyll` и `README.md` в корень репозитория.
3. Открыть **Settings → Pages**.
4. В **Build and deployment** выбрать **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Сохранить и открыть **Visit site** после публикации.

После публикации адрес будет работать через HTTPS.
