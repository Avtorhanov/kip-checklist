КИП-чеклист
Мобильный чек-лист для инженера КИПиА.

Возможности
- Добавление и редактирование тегов
- Отметка выполнения и задания
- Страницы, поиск, фильтры и 
сортировка
- Импорт из файлов и фотографий
- Сохранение и отправка результатов
- Тёмная/светлая тема и настройка шрифта
- PWA для добавления на главный экран
