# КИП-чеклист

**Сайт:** https://avtorhanov.github.io/kip-checklist/

КИП-чеклист — мобильный инженерный инструмент для работы с перечнем приборов КИПиА на объекте.

## Работа с тегами

Каждая позиция представлена технологическим тегом, например:

`2131-PZT-414A`

Для каждой позиции можно:

- отметить прибор как выполненный;
- оставить невыполненным;
- добавить инженерское задание или примечание;
- отредактировать тег;
- удалить позицию;
- выполнить поиск и фильтрацию по списку;
- добавить фотографию и использовать распознавание для поиска подходящих тегов;
- после распознавания проверить найденные кандидаты и самостоятельно выбрать нужные теги.

### Логика работы

1. Выберите нужный участок/страницу.
2. Найдите необходимый тег через поиск или фильтр.
3. Выполните работу с прибором.
4. Отметьте тег как выполненный.
5. При необходимости добавьте краткое инженерное задание или примечание.
6. Если тег нужно определить по фотографии, используйте фото → распознавание → проверка кандидатов.
7. Перед сохранением или отправкой проверьте выбранные теги и их статус.

Состояние чек-листа сохраняется на устройстве браузера. При работе с распознаванием результат следует проверять перед внесением в рабочий список: распознавание является вспомогательным инструментом, а не заменой инженерной проверки.

## PWA

Сайт можно добавить на главный экран телефона. На поддерживаемых Android-браузерах приложение может устанавливаться как PWA; на iPhone используется системная функция Safari «На экран Домой».
